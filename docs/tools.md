# Tools

Use these helper tasks from VS Code or terminal.

## New Problem

VS Code:

1. Open Command Palette.
2. Run `Tasks: Run Task`.
3. Select `New Problem`.

Terminal:

```bash
node .vscode/new-problem.js
```

Details: [new-problem.md](new-problem.md)

## Toggle Explorer Cleanup

1. Open Command Palette.
2. Run `Tasks: Run Task`.
3. Select `Toggle Explorer Cleanup`.

This switches the Explorer between clean view and full view.

Details: [workspace-cleanup.md](workspace-cleanup.md)
